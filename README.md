## What I am working on

**[Findra](https://github.com/blakazulu/findra)** - desktop search for Windows that actually finds things. Names in 0.33 to 2.05 ms across a 1.58 million file drive, plus optional search by what a photo shows, what a document means and what was said in a recording, with a second pass for Hebrew. No account, no cloud, no telemetry. C# / .NET 10, ONNX Runtime on DirectML, Whisper. [findra-search.netlify.app](https://findra-search.netlify.app)

**[Search MCP](https://github.com/blakazulu/search-mcp)** - semantic code search for AI coding agents, as an MCP server. About 400 ms per query and roughly 58x fewer tokens than grep, fully local with no API keys. Works in Claude, Cursor and Windsurf. [npm](https://www.npmjs.com/package/@liraz-sbz/search-mcp)

**[mcp-hf-images](https://github.com/blakazulu/mcp-image-server)** - image generation as an agent-callable tool, one line to install. [npm](https://www.npmjs.com/package/mcp-hf-images)

**[הדירה שלי / New Home Owner](https://new-home-owner.online)** - an AI dashboard for Israeli apartment buyers. Upload the contracts and payment documents and it builds the payment tracker, timeline and spec breakdown by itself, then answers questions over your own documents with the source cited. React 19, Firebase, Gemini, vector search.

**[ScalpelPDF](https://github.com/blakazulu/ScalpelPDF)** - a Windows PDF editor on the [Microsoft Store](https://apps.microsoft.com/detail/9n9hn8xw4lf3). Edit, sign and merge, with no account and no subscription. GPLv3.
